# 场景层 · 提示词

这个目录存放**场景相关**的提示词。换场景时整个替换。

| 文件 | 用途 | 用在哪 |
|---|---|---|
| `system.md` | 系统提示词（角色 + 铁律 + 输出格式） | `loop/` 调模型时作为 system message |
| `diagnose.md` | （待加）单独的诊断提示词 | 如需把"诊断"拆成独立一步 |

## 为什么提示词要单独成文件

1. **便于调优**——改提示词不用改代码，也不用重启
2. **便于版本对比**——`system_v1.md` / `system_v2.md`，能说清"v2 改了什么、效果提升多少"
3. **面试价值**——"我把诊断提示词从 v1 迭代到 v3，成功率从 55% 到 78%"，这是有说服力的改进记录

## 约定

- 提示词里**不要硬编码具体表名/字段名**（那是数据的事）
- 铁律部分（如"结果必须一致"）放最前面，模型更容易遵守
- 每次改提示词，在 `docs/` 里记一笔：改了什么 → 效果怎么变
